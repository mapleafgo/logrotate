# 单 worker 异步归档维护

> 历史设计记录，仅供追溯，不构成当前契约。当前职责、保留边界和错误语义见[文档索引](../../README.md)及[使用说明](../../../README.md)。

每个 Writer 最多一个归档 worker。启动及切卷唤醒 worker，不等待压缩、恢复或清理。通知可合并，磁盘待处理卷是工作依据，不在内存排队保存每卷任务。

前台继续负责活动文件同步、封存、目录同步及重新打开。后台不得处理尚未安全封存的卷；重开失败时不得清理刚封存的卷。压缩发布前保留原件；单卷恢复冲突只保护该卷，不阻止清理无关卷。

Sync 同步活动日志，不等待归档维护。Close 停止写入后等待已触发的维护收尾，并报告未恢复的维护错误。正式归档配额最终生效，不限制待处理卷暂占的磁盘空间。

不改变现有路径解析；使用相对路径时，关闭 Writer 前不得更改进程工作目录。

验收：阻塞后台维护时 Open、切卷 Write 和 Sync 仍能返回；Close 等待维护完成。核对重启恢复、故障隔离、归档编号，以及改造前后切卷 P99、关闭耗时和磁盘积压。
